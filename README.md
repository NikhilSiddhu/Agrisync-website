# agrisync.tech

Static site for AgriSync, an early-warning system for cabbage disease running in one field in Hapur, Uttar Pradesh.

- `index.html` is the whole site, with styles and scripts inline.
- GitHub Pages serves `main`; `CNAME` points it at agrisync.tech.
- `og-image.png` is the link-preview image (1200x630).
- Live field data: https://dashboard.agrisync.tech
- Station code: https://github.com/nikhilsiddhu/agrisync
